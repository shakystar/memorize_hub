# memorize_hub

Optional relay server for [memorize](https://github.com/shakystar/memorize)'s
cross-machine auto sync - a dumb store-and-forward queue of opaque per-project
event logs over HTTP.

- **[PROTOCOL.md](./PROTOCOL.md)** - the authoritative wire contract (v1)
- **[AGENTS.md](./AGENTS.md)** - design direction, invariants, roadmap

Status: docs-only scaffold; server implementation in progress.
