# memorize_hub 최종 구현·검증 상태

정리일: 2026-09-24. 구현 기준: `463aa48244683c4bd7e195ebef26764336044ad2`.

## 프로젝트 관계와 종료

Memorize는 2026 공군창업경진대회 우수상 수상 프로젝트이며, 작성자 기록상 예선 v1.0.0·결선 v3.0.0으로 출품했다. Hub는 그 프로젝트와 연결해 사용한 동기화·협업 구성 요소다. 별도 수상 이력으로 표시하거나 현재 Hub 전체를 출품 당시 구현이라고 소개하지 않는다.

후속 실험은 mori·mori-nest로 이어졌다. 군 복무 중 개발 시간, 모델 API·반복 평가 비용, 관련 도구의 등장을 함께 고려해 프로젝트군의 추가 개발·유지보수를 마무리한다. 구현·테스트와 남은 설계를 공개 기록으로 남긴다.

## 실제 구현과 경계

| 구성 | 근거 | 주의할 경계 |
| --- | --- | --- |
| relay | `packages/relay/src/store.ts`, `server.ts` 및 단위·HTTP 통합 테스트 | NDJSON 이벤트 저장·중복 제거·순서 보존. 기억 해석이나 계정 권한을 맡지 않음 |
| gateway | `packages/gateway/src/policy.ts`, `workspace.ts`, `keys.ts`, `personal-store.ts`, `device.ts`, `oauth.ts` | 계정·권한·초대·기기 로그인·Google OAuth. 정책 테스트와 실제 운영 보안 인증은 다름 |
| replica | `packages/replica/src/author.ts`, `read-lane.ts`, `tasks.ts`, `timeline.ts` | `@shakystar/memorize@3.0.0-dev.68`을 사용. 최신 CLI와 버전이 자동으로 일치하지 않음 |
| 웹 | `packages/web/src/components/`, `packages/web/tests/` | 워크스페이스·작업·타임라인 화면. 모든 사용자 흐름의 브라우저 검증을 뜻하지 않음 |
| 과거 gateway | `packages/gateway-legacy/` | 동결 참고 코드. workspace에서 제외되어 현재 `pnpm -r check`에 포함되지 않음 |

SoT와 계획 문서는 작성 당시의 결정이다. `H900`의 ‘나중에 구현’ 표현이 현재 개발 약속으로 이어지지는 않는다. 일부 항목은 이후 구현이 들어갔으므로 문서의 오래된 진행 상태만으로 판단하지 않는다.

## 검증 근거

- **실제 물리 기기 두 대의 동기화를 테스트했으며 작성자와 팀원이 실제로 사용했다.** 작성자가 2026-09-24 최종 정리 중 직접 확인했다. 아래 저장소 내 컨테이너 실험과 별개의 검증·실사용 근거다. 사용 기간·사용자 수·물리 기기 환경·지연의 수치 기록은 추가로 특정하지 않는다.

- [기준 커밋 CI 29631031536](https://github.com/shakystar/memorize_hub/actions/runs/29631031536): 성공. `check`는 현재 workspace의 타입 검사·린트·테스트를 실행한다. 독립 실행하는 e2e 스크립트는 이 명령에 포함되지 않는다.
- `sandbox/RESULTS.md`의 2026-06-27 기록: 동일 WSL2 Docker 환경의 두 컨테이너가 공개 배포 Hub에 접속했다. 각 클라이언트는 `memorize@2.4.0`과 별도 `MEMORIZE_ROOT`를 사용했다.
- A→B 3개 이벤트, B→A 1개 이벤트가 전달됐고, 로컬 `sync.*` bookkeeping을 제외한 복제 이벤트 집합의 바이트 일치를 확인했다. 이 컨테이너 실험의 수치를 별도로 확인된 물리 기기 동기화 테스트의 측정치로 사용하지 않는다.
- push+pull 5회 총 소요 시간은 9,086 / 5,023 / 4,907 / 4,100 / 4,244ms, 평균 5,472ms다. CLI 시작·DB 열기·서버 기동을 포함한다. relay 단독 지연이나 현재 버전의 성능으로 표시하지 않는다.
- 이번 최종 정리에서 운영 Hub에 테스트 이벤트를 쓰거나 유료 모델 평가를 실행하지 않는다.

## 완료로 주장하지 않는 범위

- 작성자·팀원 실사용을 넘어서는 대규모 사용자·장기 운영·대규모 데이터에서의 안정성
- 모든 버전의 Memorize 클라이언트 및 외부 에이전트와의 호환성
- 서버 알림 채널, 로그 retention/compaction, 결제 tier·quota의 완성
- E2E 키 배포·기기 분실 복구 정책을 포함한 제품 전체의 암호화 완성
- 원격 MCP와 UI·replica의 모든 흐름을 포함한 현재 버전 종단 간 검증

열린 이슈 #3–#8에는 이후 일부 구현과 겹치는 오래된 항목이 있다. 종료 처리 시 전체 미구현으로 단정하지 않고 구현 근거와 미검증 범위를 이 문서로 구분한다. PR #64의 CLI 온보딩 문구 변경은 병합하지 않은 기록으로 보존한다.

## 공개·라이선스와 자동 실행

현재 소스는 2026-09-24부터 MIT로 공개한다. 루트와 각 패키지의 라이선스 메타데이터를 맞추고, 외부 구성 요소의 라이선스는 유지한다. 과거 Sustainable Use License 고지는 이전 버전에 남아 있다.

종료 정리의 main 반영으로 운영 서비스가 재배포되지 않도록 CI의 Fly 자동 배포 작업을 제거한다. PR의 코드 검사·Docker 이미지 빌드 검증은 남긴다. 이 변경은 Fly 앱·볼륨·도메인·OAuth 설정·운영 데이터의 삭제나 비용 종료를 의미하지 않는다.

신규 기능, 정기 유지보수, 보안 업데이트는 계획하지 않는다. 소스의 자체 호스팅 참고 자료와 외부 운영 서비스의 상태를 구분한다.
